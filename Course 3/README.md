# 🚀 Course 03: Introduction to Programming with C++ – Level 1
> **Connecting logic to code: Translating algorithmic thinking into executable C++.**

---

## 📌 Overview
After establishing a solid understanding of computer hardware in Course 01 and mastering language-agnostic logic in Course 02, **Course 03** introduced my very first programming language: **C++**.

The core philosophy of this course: **C++ is a tool, not programming itself.** Instead of blindly memorizing syntax, I focused on using C++ to implement the problem-solving patterns and flowcharts built in earlier courses. Learning C++ first provided a low-level understanding of memory, data types, and execution efficiency that makes learning any future language easier.

---

## 🔑 Key Concepts & What I Learned

### 1. Fundamentals & Core Constructs
- **Environment Setup:** Configuring Visual Studio and understanding the build, compilation, and linking cycle for C++ applications.
- **Variables & Data Types:** Memory allocation for primitive types (`int`, `float`, `double`, `char`, `bool`), type conversion, and calculation priorities.
- **Console I/O:** Managing standard user input (`cin`) and output (`cout`) formatted streams cleanly.

### 2. Control Flow & Reusable Logic
- **Conditional Logic:** Implementing decision-making constructs (`if`, `else if`, `else`, `switch`).
- **Iteration (Loops):** Mastered repeating execution using `for`, `while`, and `do-while` loops.
- **Functions & Scope:** Modularizing code into clean, reusable functions, understanding parameter passing (by value vs. by reference), and variable scope rules.

### 3. User-Defined Types & Data Structures
- **Structures (`struct`):** Grouping related variables into custom data models.
- **Enums (`enum`):** Creating readable, type-safe symbolic constants.
- **Arrays:** Allocating and manipulating fixed-size single-dimensional sequences of data in memory.

---

## 💡 Personal Reflection & Impact

> *"Syntax is easy to Google; structured logical execution is what makes a real engineer."*

**My Key Takeaway:**  
Moving from flowcharts to actual C++ code felt natural because the problem-solving foundation was already built. Starting with a strict, statically-typed language like C++ forced me to write disciplined code, pay attention to data types, and understand how values are handled in memory.
