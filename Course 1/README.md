# 🧠 Course 01: Programming Foundations – Level 1
> **Building the mental model before typing a single line of code.**

---

## 📌 Overview
Before jumping into syntax, frameworks, or writing code, I started my journey with **Programming Advices (Course 01)** to answer one core question: *How do computers actually think and process data under the hood?*

Instead of rushing straight into a language, this course built my foundational understanding of how computers represent information, how memory works, and how code eventually turns into hardware execution. Understanding these fundamentals first gave me a massive advantage when moving into C++ and algorithm design later in the roadmap.

---

## 🔑 Key Concepts & What I Learned

### 1. Data & Information Processing
- **The Data Hierarchy:** Breaking down the exact transition from raw **Data $\rightarrow$ Information $\rightarrow$ Knowledge $\rightarrow$ Wisdom**.
- **Hardware Fundamentals:** Understanding internal computer components, execution cycles, and performance/speed metrics.

### 2. Number Systems & Data Representation
- Mastered representation in **Binary (Base-2)**, **Octal (Base-8)**, and **Hexadecimal (Base-16)**.
- Practice with manual conversions between number systems and leveraging programmer calculators correctly.
- Deep dive into memory terminology: bits, nibbles, bytes, and memory alignment concepts.

### 3. Translation & Language Levels
- Deconstructed how low-level vs. high-level programming languages interact with hardware.
- Learned the mechanical differences between **Compilers, Interpreters, Assemblers, and Linkers**.
- Understood variable storage in memory, operator precedence, and basic arithmetic execution logic.

---

## 💡 Personal Reflection & Impact

> *"Most beginners fail because they memorize syntax without understanding the machine."*

**My Key Takeaway:**  
This course completely altered how I approach programming. Knowing what actually happens inside CPU registers and memory when a variable is declared stopped me from guessing how code works. It built the exact mental model I needed to learn advanced C++ concepts in later courses without getting stuck.
